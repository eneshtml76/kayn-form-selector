# 🗡️ League of Legends - Kayn Form Selector

An interactive, responsive web application inspired by League of Legends. This project allows users to dynamically switch between **Kayn's** forms (**Shadow Assassin** or **Darkin Rhaast**) with smooth animations, dynamic color shifts, and fully updated skill logs in English.

Designed as a key piece of my modern front-end developer portfolio.

## 🚀 Live Preview Features
* **Dynamic Styling**: The entire website's background color dynamically adapts to the selected form (Deep Blue for Shadow, Crimson Red for Darkin).
* **Smooth UI/UX Interactions**: Interactive buttons featuring custom `:hover` elevation effects and `:active` click feedback.
* **Skill Unlock System**: Modifies the DOM via JavaScript to display specific character abilities upon form activation.
* **Fully English UI**: Built entirely in English to align with global development standards and international portfolios.

## 🛠️ Tech Stack Used
* **HTML5**: Formulated structural semantics and image/button components.
* **CSS3**: Implemented modern **Flexbox** layout systems, interactive transition effects (`transform`, `opacity`), and glowing shadows.
* **JavaScript (ES6+)**: Dominated DOM manipulation, handling dynamic image sources, context switching, and class logic injections.
